# Network-Intrusion-Detection-System-Signature---Based-
This is a web - based Network Intrusion Detection System, that captures live packets and monitors them. It consiste of 5 signatures that we made - Whatsapp application, Brave Browser, Youtube.com, Leetcode.com, GeeksForGeeks.com. So whenever the system opens these 2 apps, or logs in to these 3 websites, it treats them as suspicious traffic.
